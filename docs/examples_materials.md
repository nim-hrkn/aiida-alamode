# example の各物質は何をテストしているか

`example/` の 3 本のドライバ（`run_alamode_phonons.py`、`run_alamode_scph.py`、`run_alamode_qha.py`）は
ALAMODE の tutorial の物質を、DFT の代わりに MatterSim（または他の ASE calculator）で、AiiDA 経由で計算する。
ここでは各物質が物質科学としてどういうテストかを解説する。SrTiO₃ は tutorial（`alamode_test/SrTiO3`）の SCPH 例で、
ドライバには含めていない。手順の詳細は [examples_workflow.md](examples_workflow.md) を参照。

## Si：調和近似が成り立つ基準物質、3 フォノン散乱の熱伝導率

- **物理**。ダイヤモンド構造の単元素半導体で、共有結合が強く、フォノンは T = 0 の調和近似で完全に安定（虚数モードなし）。
  バンドは音響 3 枝と光学 3 枝で、Γ 点の光学モードは約 15.5 THz。極性がないので LO と TO の分裂はない。
- **テストの意味**。
  1. **調和 IFC の最小構成の検証**。対称性が高く、2×2×2 supercell で変位パターンは 1 個だけ。分散が DFT と合えば、
     変位、力、DFSET、alm、anphon の一連の配線が正しいことが確認できる。
  2. **3 次 IFC と格子熱伝導率**。Si は κ = 150 W/mK 程度と大きく、Umklapp 散乱だけで決まる典型例。RTA で κ(T) が
     T⁻¹ 前後で減る様子、フォノン寿命の振動数依存、平均自由行程で分けた累積 κ（数百 nm のフォノンが半分を運ぶので、
     ナノ構造化の議論の出発点）、境界散乱の効果を見る。
  3. **力場の精度の指標**。κ は 3 次 IFC の 2 乗に敏感なので、MatterSim と DFT で調和分散はよく合っても κ は 3 割ずれる
     （300 K で 149 対 113 W/mK）。「調和はよいが非調和は要注意」という力場の性格が出る。

## PbTe：極性物質の LO-TO 分裂と長距離力、非調和の強い熱電材料

- **物理**。岩塩構造の熱電材料で、イオン性があり Born 有効電荷が大きい（Pb で約 +6）うえ、誘電率が大きい（ε∞ ≈ 33）。
  Γ 点で LO と TO が分裂する。TO モードは非常に柔らかく（1 THz 程度）、強い非調和性の原因で、κ が約 2 W/mK と低い理由。
- **テストの意味**。
  1. **非解析項の扱い**。有限の supercell では長距離の双極子相互作用が切れるため、NONANALYTIC = 0 では Γ 点の LO が TO と
     縮退したままになる。NONANALYTIC = 1（Parlinski の混合）、2（Gonze の混合）、3（Ewald 法で双極子項を明示的に分離）の
     3 つの補正法で分散がどう変わるかを比べる。Ewald 法は supercell の原子配置と基本胞の対応に厳密で、
     「translation 1 が基本胞の位置と一致していない」supercell では誤った分散が出る（`make_diagonal_supercell` の理由）。
  2. **BORNINFO の入力**。誘電率テンソルと Born 有効電荷を外部から与える経路の検証（MatterSim は電荷を出せないので
     tutorial の DFT の値を使う）。
  3. **柔らかい TO モードの再現**。X 点や Γ 点近傍の TO の低下が力場で出るかを見る。これが出ないと PbTe の低い κ は再現できない。

## SrTiO₃：T = 0 で不安定な立方相を SCPH で安定化する（tutorial の SCPH 例）

- **物理**。立方ペロブスカイトの SrTiO₃ は、調和近似では R 点（と M 点）に虚数の振動数を持つ。TiO₆ 八面体の回転モードで、
  実際に 105 K 以下で正方相へ転移する（反強誘電的な八面体回転）。Γ 点の強誘電的なソフトモードも量子揺らぎで転移直前に
  止まる「量子常誘電体」として有名。
- **テストの意味**。
  1. **虚数モードのある物質の有限温度フォノン**。4 次の IFC まで含めた自己無撞着フォノン（SCPH）で、高温では R 点のモードが
     実数になり、温度を下げると軟化して虚数に近づく（ソフトモード）ことを示す。調和近似では意味を持たない物質を扱えるか
     どうかの検証。
  2. **LASSO による高次 IFC の推定**。4 次までの IFC は数が多く、MD の構造からの疎な回帰（elastic-net、cross validation）で決める。
  3. `run_alamode_scph.py` をそのまま SrTiO₃ に使えるが、SrTiO₃ の転移は八面体回転（R 点）なので RELAX_STR = 1 の
     基本胞内の原子変位では正方相を表せず、SCPH の分散（R 点の軟化）を見る使い方になる。

## BaTiO₃：強誘電転移、有限温度の構造緩和

- **物理**。同じペロブスカイトでも BaTiO₃ は Γ 点の強誘電的ソフトモード（Ti が O 八面体の中でずれる）が不安定で、393 K で
  立方相から正方相へ転移し、さらに斜方晶、菱面体晶へと続く。T = 0 の調和近似では立方相に虚数モードがある。
- **テストの意味**。
  1. **SCPH と構造緩和の組み合わせ（RELAX_STR = 1）**。各温度で非調和自由エネルギーを最小にする原子位置を求める。高温では
     Ti の変位が 0 に戻り立方相、低温では有限の変位を持つ正方相になり、変位が消える温度が転移温度。MatterSim で
     350〜400 K、tutorial の DFT（PBEsol）では 150〜175 K、実験 393 K。転移温度は力場のわずかなエネルギー差に敏感で、
     力場の非調和の質を測るテストになる。
  2. **数値的な安定性**。1 次転移に近いため、構造緩和の Newton 反復が特定の温度で発散することがある（NaN）。
     ADD_HESS_DIAG や混合係数で抑える必要があり、SCPH の設定の検証も兼ねる。
  3. **SrTiO₃ との対比**。同じ構造で、Γ 点が不安定（BaTiO₃、強誘電）か R 点が不安定（SrTiO₃、八面体回転）かの違いが、
     有限温度のフォノンと構造にどう出るかを比べられる。

## ZnO：異方的な熱膨張、準調和近似の構造最適化

- **物理**。ウルツ鉱（六方晶）の ZnO は a 軸と c 軸で熱膨張率が異なる。調和近似ではフォノンの振動数が体積に依存せず
  熱膨張が出ないので、体積とひずみに対するフォノン振動数の変化（Grüneisen パラメータ）から準調和近似（QHA）で求める。
  低温でわずかに負の熱膨張を示すことも知られている。
- **テストの意味**。
  1. **多軸の QHA 構造最適化**。立方晶なら体積 1 変数だが、六方晶では a と c の 2 変数（一般にはひずみテンソル 6 成分）を
     同時に最適化する。6 種類のひずみ下の調和 IFC、弾性定数（2 次と 3 次）、ひずみと力の結合を入力にして、各温度で
     自由エネルギーを最小にするひずみ u_xx と u_zz を求める。
  2. **3 つの近似のスキームの比較**。full QHA、ZSISA（内部座標は静的な力の釣り合いで決める）、v-ZSISA（体積だけ QHA で
     決める）の差を見る。ZnO ではこれらの差は小さく、その確認自体がテスト。
  3. **力場の異方性の再現**。DFT では a 軸の方が c 軸より速く伸びるが、MatterSim では c 軸の膨張が約 2 倍大きく異方性が
     逆になった。熱膨張は非調和の 1 次の効果（3 次 IFC とひずみの結合）で決まるので、Si の κ と同様、力場の非調和の
     精度がそのまま出る量。
  4. **ひずんだ格子の IFC**。平衡でない格子では無変位構造にも力が残るため、それを差し引く offset（`subtract_offset`）が必要。
     落とすと fitting error が 96 % になる。

## Born 有効電荷と ε∞ の検証軸

PbTe、BaTiO₃、BaZrO₃、BaHfO₃、ZrO₂ の LO-TO 補正には Z* と ε∞ が要る。力場（MatterSim など）はどちらも出せないので、
Z* は SevenNet-Polar（Ba, Ca, Hf, Li, O, P, Pb, Sr, Ti, Zr の系）、ε∞ は AnisoNet で予測し、`BornInfoWorkChain` で
BORNINFO にする。検証は「文献の DFT 値との一致」（Z* は BaTiO₃ で Ba 2.72 / Ti 7.72 / O −2.15, −6.14、ε∞ は
BaZrO₃ 4.93、MgO 3.13）と「NA3 で Γ 点の LO が上がり TO は動かないこと」で行う。詳細と表は
[born_effective_charges.md](born_effective_charges.md)。PbTe は Te が未学習のため tutorial の DFT の BORNINFO を使う。

## まとめ

| 物質 | 調和近似で安定か | 検証している物理 | 力場に効く量 |
|---|---|---|---|
| Si | 安定 | 分散、3 フォノン散乱、κ | 3 次 IFC |
| PbTe | 安定だが TO が柔らかい | LO-TO 分裂、非解析項の補正 | Born 電荷、柔らかいモード |
| SrTiO₃ | R 点が不安定 | SCPH による有限温度の安定化、ソフトモード | 4 次 IFC |
| BaTiO₃ | Γ 点が不安定 | 強誘電転移、有限温度の構造緩和 | 4 次 IFC、微小なエネルギー差 |
| ZnO | 安定 | 異方的熱膨張、QHA 構造最適化 | 3 次 IFC とひずみの結合、弾性定数 |

Si と PbTe が「調和近似の範囲で正しく動くか」、SrTiO₃ と BaTiO₃ が「調和近似が破綻する物質を有限温度で扱えるか」、
ZnO が「格子定数の温度変化を扱えるか」のテストという構成になっている。
